# Task Manager REST API

A structured REST API built with **Python and FastAPI** as part of Module 5 – Advanced Python Application Development.

The project demonstrates REST API development, SQLite database integration, CRUD operations, API-key authentication, schema validation, Swagger API testing, and Git/GitHub workflow.

---

## 🚀 Project Overview

The Task Manager API allows users to create, retrieve, update, and delete tasks through RESTful API endpoints.

The project was developed to practice backend application development using FastAPI and to understand how an API communicates with a database.

### Main Features

- FastAPI REST API
- Structured API routes
- SQLite database integration
- Full CRUD operations
- API-key authentication
- Request/response schema validation
- Automatic Swagger API documentation
- API endpoint testing
- Modular project structure
- Git/GitHub version control

---

## 🛠️ Technologies Used
